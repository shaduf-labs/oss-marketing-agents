Research decision · 23 Sep 2026

Loopmark Agent: retain the slot with a stricter label.

Decision: retain Loopmark only as an exploratory local drafting CLI. It is not a team-approval system, managed scheduler, CRM, or production/unattended publishing service.

Decision card

Retain, do not recommend broadly

Technical solo operator; local and draft-only

Use only for a fictional-data drafting experiment with social credentials absent. The checked material supports a local CLI and local JSON records, not managed marketing operations.

Hands-on status
No hands-on install or test occurred.
License
MIT for the named repository.
Replacement decision
MarketingOS AI was examined but is not recommended.

MarketingOS AI is not a recommendation and is not catalogued as a product. Its claimed approval boundary made it a useful comparison, but it does not clear the replacement threshold.

Draft-only first test

Plan, not a performed testUse a disposable local data directory, fictional brief and invented leads. If separately approved, use a restricted low-spend test key. Leave LangSmith, X, LinkedIn, and Buffer credentials absent. Generate only a draft email and three-post content calendar; inspect the local JSON and clean up afterward.

Do not import customer or CRM data, schedule, send, post, resolve a real complaint, mutate a CRM, use production credentials, or run any social integration. Record unresolved setup, error, data-path, and cleanup questions before any later evaluation.

Replacement threshold

Replace this slot only with a narrow OSS marketing-agent application that has primary evidence for an exact OSI-style license and scope, an installable tagged release or verifiable package tied to source, documented credential/data path and no-action mode, approval or enforced draft-only external-action boundary, durable state with backup/restore guidance, retry/error/run visibility or an explicit limit, and a usable security disclosure route.

Uncertainty and exclusions

  • No hands-on test occurred. Installation behavior, output quality, provider handling, reliability, and error behavior were not independently measured.
  • External providers are separate decisions: Loopmark can send data to OpenAI and optional providers; MarketingOS AI’s live path can involve Supabase, Clerk, OpenAI, and HubSpot.
  • Hosted/proprietary products, documentation-only connectors, broad runtimes/frameworks, and broad marketing teams were excluded from this narrow-agent slot. MarketingOS AI alone was compared because its documented approval-first boundary was relevant.
  • No autonomous action is recommended.
