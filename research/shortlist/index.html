Research comparison · verified 22 Sep 2026

Four marketing-work layers, plus an n8n license comparison.

Choose the lowest layer that can do the job with a named owner, a human review step and a cleanup route. n8n is shown beside Activepieces CE to make the source-available versus OSI-style license boundary clear.

Decision rule

Use Mautic for an owned marketing system; Activepieces CE for cross-system triggers and transformations; Marketing Agent OS for planning or research in an existing harness; and Loopmark only as an exploratory local drafting CLI. Use n8n only after checking its source-available license against the intended use and assigning an operator.

License guardrail: n8n and Activepieces CE

n8n: public code and self-hosting do not make it OSI-style open source. Its Sustainable Use License restricts commercial provision/hosting. Read the license, the official FAQ and the n8n dossier.

Activepieces CE: the prior verified report identified MIT for Community Edition/outside named EE paths. That is a component/path boundary, not a claim that every repository path or enterprise feature is MIT. Read the Activepieces CE dossier.

Do not infer more than the evidence supports

No connector was tested. A node or piece entry does not establish permissions, target API behavior, data handling, retries, costs, consent, deliverability or production readiness. Read the dossier before connecting a real system.
